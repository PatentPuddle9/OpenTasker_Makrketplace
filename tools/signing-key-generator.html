OpenTasker Marketplace key generator

Creates the ECDSA P-256 key pair used to sign and verify the official marketplace catalogue.

Generated in your browser only.

This page uses the browser's built-in Web Crypto API. It makes no network requests and does not save keys to browser storage. Download/open a local copy of this HTML file before generating keys.

Important: these are a matching pair, not the same secret.

The private-key value goes only in the Marketplace repository. The public-key value goes in the OpenTasker app repository. Never put the private key in the app or share it.

Ready.

Add as MARKETPLACE_SIGNING_PRIVATE_KEY_B64 in PatentPuddle9/OpenTasker_Makrketplace.

Add as MARKETPLACE_PUBLIC_KEY_X509_BASE64 in PatentPuddle9/OpenTasker_.

Keep this backup private. Never commit or share it.

After adding the two secrets:
  1. Run Build OpenTasker APK on Experimental.
  2. Run Publish signed marketplace catalogue in the Marketplace repository.
  3. Install the new APK. The app stays fail-closed until rebuilt with the public key.
